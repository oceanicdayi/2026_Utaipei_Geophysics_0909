## 2. 當日探究歷程（10 個階段）

課程設計不是器材操作的流水帳，而是一個完整的科學建模歷程：

> **提出問題 → 設計觀測 → 取得證據 → 找出規律 → 建立模型 → 檢驗修正**

| # | 階段 | 核心提問 | 當日實作重點 |
|---|---|---|---|
| 01 | 問題情境與儀器認識 | 「地下看不到，我們要怎麼知道下面有什麼？」 | 教師於校園現場介紹折射震測目的與整套設備；建立「不是直接看地下，而是用震波取得證據」的觀念 |
| 02 | Hammer、trigger 與 t = 0 | 「如果不知道震源何時發生，我們能計算震波走了多久嗎？」 | 榔頭敲擊鐵板產生人工震源；榔頭感測器回傳 trigger，震測儀將敲擊瞬間定義為 **t = 0** |
| 03 | 量距、座標與受波器布設 | 「只有波形沒有位置，能不能建立地下模型？」 | 以皮尺建立測線與位置基準，**每 2 m 插設一支受波器**，強調與地面的良好耦合 |
| 04 | 受波器、訊號線與 channel | 「感測器量到振動之後，資料怎麼回到震測儀？」 | 學生配線並確認每個觀測點對應正確的 channel 與位置（data provenance） |
| 05 | Seismograph → Computer | 「一個科學量測系統，需要哪些環節同時正確？」 | 訊號線、trigger、車用電池、電腦通訊線全部接入震測儀，完成同步記錄與傳輸 |
| 06 | 震源位置、鐵板、重複敲擊與取樣率 | 「為什麼不是敲一次就好？為什麼儀器設定也會影響結果？」 | 說明 shot point 決定方式、鐵板作為穩定耦合面、**重複敲擊疊加提高訊噪比**；並說明取樣率與時間解析（本次 **0.25 ms**） |
| 07 | First arrival、直達波與折射波 | 「螢幕上一堆波形，哪一個資訊最關鍵？」 | 帶學生判讀 first arrival：近距離常由直達波先到，遠距離可能轉由折射波先到；每個 channel 整理成一組 (distance, arrival time) |
| 08 | 第一個震源點：操作、觀察、判斷 | 「自己產生的資料，夠不夠好到可以拿來建模？」 | 學生在 0 m 反覆敲擊並**立即檢視訊號**，判斷是否需要再敲、是否有接觸不良或環境雜訊 |
| 09 | 多震源觀測 | 「為什麼要一直移動震源，而不是只在一個位置量一次？」 | 每 4 m 一個 shot point，從 0 m 到 44 m，共 **12 炮**；改變的是震源位置而非地下，每一組資料都在檢驗同一個地下模型 |
| 10 | 場地復原與後續建模 | 「量完資料之後，下一個真正的科學問題是什麼？」 | 拆收器材、清點、回復場地；並說明野外結束後才是分析的開始：挑 first arrival → 建 travel-time curve → 檢查斜率改變 → 提出並修正速度模型 |

## 4. CER 檢核點：把觀測變成可以辯護的解釋

| 要素 | 內容 |
|---|---|
| **C · Claim（提出模型）** | 地下可能不是單一均勻介質，而至少存在兩個速度不同的層。 |
| **E · Evidence（指出證據）** | distance–time 資料呈現**兩段不同斜率**，且遠距離 first arrival 的趨勢改變。 |
| **R · Reasoning（連結證據與模型）** | 在 t–x 圖上**斜率為 1/v**；斜率改變代表控制 first arrival 的傳播速度與路徑發生改變。 |

當資料無法再用單一斜率解釋時，學生就有理由修正原先「均勻地下」的模型。

> 關鍵直覺：**「走得最短，不一定最早到。」**
> 近距離由直達波先到；距離拉長後，經由高速下層傳播的折射波反而可能先抵達。

## 7. 課程收束與延伸

**這個實驗可以看到什麼？實際應用在哪裡？**

- **它不是地下照片**：震測首先提供的是**速度差異**與**界面可能的位置**；要推論地下的材料與構造，必須再結合地質、鑽井或其他資料。
- **它可以協助我們**：估計岩盤深度、風化或鬆散層厚度、工程基地地下條件、邊坡與地質結構，以及其他近地表地球物理問題。
- **更大的科學問題**：人類如何研究一個無法直接看見的世界？地球物理的核心，就是用可觀測的證據，建立對不可見結構的模型。

> **科學不只是「看見」。**
> 真正的科學，是利用觀測與證據，建立能夠解釋世界的模型，並持續用新的資料檢驗與修正它。

## 8. 後續作業銜接

1. 從 `202610_UTELS.sgy`（或 `202610_UTELS.pdf` 的 12 頁 shot gather，時窗 0–0.1 s）逐道挑選 first arrival。
2. 整理成 (distance, time) 資料，繪製 **t–x 走時曲線**，12 炮可同圖比較。
3. 檢核**互換時間**：A→B 與 B→A 的總走時應相等，可用來驗證挑選品質。
4. 找出斜率轉折（crossover distance），以截距時間法求 V₁、V₂ 與界面深度；進階可用時間項法或 GRM。
5. 以 CER 格式寫出結論：Claim（你的地下模型）、Evidence（哪幾段斜率、哪些數字）、Reasoning（為什麼這些證據支持這個模型）。
