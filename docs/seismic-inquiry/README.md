- **互動模組**：震源位置／source–receiver distance、兩層速度模型 travel-time curve
- **CER 科學論證**與科學建模收束

## 實驗結果摘要

全部由 `data/202610_UTELS.sgy`（288 道）計算。**計算用的 Python 程式完整公開在 [`analysis/`](../../analysis/)**，任何人重跑都會得到相同數值（`python analysis/scripts/run_all.py`）。

- 288 道全部有訊號，無死道
- 近支距訊噪比中位數約 56 dB；**超過約 30 m 後中位 SNR 低於 12 dB**，初達波埋入雜訊
- 206 / 288 道（72%）SNR ≥ 25 dB
- 資料中能量最強的是**表面波（ground roll）**，視速度僅約 160 m/s
- 單一直線擬合視速度約 470 m/s，殘差 rms 達 11.1 ms — 單層模型解釋不了這組資料
- 互換時間檢核：35 組配對，中位差 1.5 ms

### 穩定度檢驗改變了結論

把自動挑選的視速度搜尋視窗下限掃過 160–300 m/s，看每個支距分組的結果變動多少：

- **支距 8–14 m**：視速度穩定在 **533–578 m/s**（變動僅 2–9%），可以採信。
- **支距 < 8 m**：變動 55–88%，結果由**挑選參數**決定而非資料。
- **支距 > 14 m**：訊噪比已不足。

兩層模型需要兩段斜率：近支距的直達波給 V₁、遠支距的折射波給 V₂。**自動挑選只穩穩拿到折射段，拿不到 V₁ 所在的近支距段。**

**因此網站不提供 V₁、V₂ 與界面深度的「標準答案」。** 這不是程式缺陷，而是方法在這組資料上的真實極限；近支距必須人工逐道判讀。互動模組中的 300／900 m/s、2.5 m 是教學示意參數，網站已明確標示不代表實測反演結果。

## 檔案結構

```text
index.html          # 教學內容與各區塊
style.css           # 版面
script.js           # 互動模組 + 實驗結果圖表

.nojekyll
assets/
  images/           # 60 張現場照片
  video/            # 現場影片
data/
  202610_UTELS.sgy          # SEG-Y，288 道，幾何已套入（建議由此開始）
  seg2/101.dat … 112.dat    # 儀器直出的 SEG-2 原始檔
  202610_UTELS.geom         # 幾何定義檔
  202610_UTELS.pdf          # 12 頁 shot gather（0–0.1 s），可列印做人工挑選
  first_breaks.csv          # 自動挑選結果與每道 SNR
  sensitivity.csv           # 穩定度檢驗的完整數值
  analysis_README.md        # 分析程式的安裝與使用教學
  202610_UTELS_野外紀錄紙.pdf
  202610_UTELS_當日活動紀錄.md
```

分析程式本身在倉庫根目錄的 [`analysis/`](../../analysis/)。
